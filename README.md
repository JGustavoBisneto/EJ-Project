# PimpimBites

Uma vitrine digital para a marca fictícia **PimpimBites**, criada para apresentar uma experiência de navegação interativa para uma linha imaginária de petiscos que visam tornar possível a comunicação entre humanos e animais, onde por meio do petisco da Pimpim Bites o humano ganha poderes para falar com os animais conforme o petisco escolhido.

O projeto foi desenvolvido como exercício de desenvolvimento front-end para ser apresentado no processo seletivo da Empresa Júnior. A proposta reúne catálogo de produtos, conteúdo editorial e recursos de interação em uma única página.

## Funcionalidades

- Navegação por seções com menu suspenso para as categorias de animais.
- Catálogo organizado em quatro categorias: domésticos, marinhos, savana e voadores.
- Cards de produto interativos que abrem um diálogo (`<dialog>`) com nome, imagem e descrição.
- Fechamento do diálogo pelo botão, pela tecla `Esc` ou clicando fora da janela.
- Alternância entre tema claro e escuro, com preferência salva no navegador.
- Carrossel automático de notícias, com controles para escolher uma notícia e pausa ao passar o mouse.
- Seções de avaliações, vídeo de apresentação e informações de contato e pagamento.
- Layout adaptável a diferentes larguras de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro (sem bibliotecas ou frameworks)

## Como executar

O projeto não precisa de instalação de dependências ou processo de build.

1. Clone o repositório:

   ```bash
   git clone https://github.com/JGustavoBisneto/EJ-Project.git
   ```

2. Abra a pasta do projeto no VS Code.
3. Abra `index.html` diretamente no navegador ou use uma extensão de servidor local, como o Live Server.
